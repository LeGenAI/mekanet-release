# Data Availability

No public data files are distributed in this directory.

## Purpose Of This Folder

This folder now exists only to document repository scope and to make it explicit that patient-derived tabular artifacts are not part of the public release.

## Not Included

The following are not publicly distributed here:

- patient-level source tables
- feature-engineered CSV exports
- image manifests
- external validation image files
- control/patient cohort bookkeeping used in the manuscript

## Reproducibility Note

The public codebase preserves the experiment structure, but any run that depends on private clinical or image-derived tables requires user-supplied inputs outside this repository.
